# Security

WBTV is built for a home network. By default it has no login; you can turn on a password and access key in **Setup > Settings > Security**, and you should put it behind HTTPS (a reverse proxy) if it is ever reachable from the internet.

## Reporting a vulnerability

Please **do not** open a public issue for a security problem. Use GitHub's private reporting instead: the **Security** tab of this repository, then **Report a vulnerability**. Include what you found, how to reproduce it, and the WBTV version (`/api/status`). I'll acknowledge it as soon as I can and credit you in the fix if you like.
